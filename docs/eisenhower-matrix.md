# Eisenhower Matrix — NBA Game Finder

## Do — Important and Urgent (MVP)
1. Allow users to select and edit their favorite NBA teams.
2. Retrieve real NBA schedules and team records using an API.
3. Display weekly recommended games based on an adjustable competitiveness filter (default 10 percentage points), with an option to show all games involving selected teams.

## Schedule — Important and Not Urgent (V2.0+)
1. Send notifications when recommended games are about to start.
2. Allow users to select their favorite NBA players.
3. Allow users to bookmark games and create a personal watchlist.

## Delegate — Not Important and Urgent (Use a Library)
1. Use Java Swing to create the graphical user interface.
2. Use Gson to parse JSON data returned by the NBA API.
3. Use Java's HttpClient library to handle API requests.

## Delete — Not Important and Not Urgent (Cut It)
1. Allow users to add games to their personal calendar.
2. Add user accounts, passwords, and social features.
3. Display notable team injuries that could reduce the competitiveness of a matchup.
