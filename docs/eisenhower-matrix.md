# Eisenhower Matrix — NBA Game Finder

Transcribed from the completed "MVP Eis.pdf" matrix.

## Do — Your MVP (Important / Urgent)
- Allow users to select and edit their favorite NBA teams.
- Get NBA schedules and records using free API.
- Display weekly recommended games based on competitiveness filter (difference in win% that the user can adjust).

## Schedule — For V2.0 (Important / Not Urgent)
- Send notifications before games start.
- Allow users to select favorite NBA players and search for games where they play.
- Allow users to bookmark games and add to a watchlist.

## Delegate — Use a Library (Not Important / Urgent)
- Use Java Swing to create the GUI.
- Use GSON to parse JSON data from the API.
- Use Java's HttpClient to handle the API requests.

## Delete — Cut It (Not Important / Not Urgent)
- Allow users to add the games to their calendar.
- Add user accounts and social features.
- Display notable injuries that would change the game's competitiveness.
